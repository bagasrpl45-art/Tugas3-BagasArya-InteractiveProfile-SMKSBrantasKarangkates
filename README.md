# Portofolio Bagas Arya — Modul 3

Website profil digital interaktif yang saya kembangkan dalam Kelas Industri UBIG. Proyek ini menambahkan JavaScript untuk menghadirkan fitur Dark/Light Mode dan modal kontak.

## Tampilan

![Tampilan profil interaktif](profileresponsive.png)

## Fitur

- **Dark/Light Mode** — Mengubah tema tampilan website.
- **Modal Kontak** — Menampilkan popup informasi kontak.
- **Event Listener** — Merespons klik pengguna.
- **DOM Manipulation** — Mengubah tampilan melalui JavaScript.

## Teknologi

- HTML5
- CSS3
- JavaScript
